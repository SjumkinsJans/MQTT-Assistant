You can send commands either through CLI or by sending them to topic mqtt-assistant/+.  
In second case, instead of + write any of available commands from list below :  
  
available commands :  
name/назвать (device last 6 MAC characters) (relay. If nothing is entered there, then 1) (name to give)  
forget/забыть (name)  
turnon/включить (given name)  
turnof/выключить (given name)
